## riscv-pk

```bash
../configure --prefix=/opt/riscv --host=riscv64-unknown-elf
```

Replace
```
CC            := gcc
READELF       := readelf
OBJCOPY       := objcopy
```
with
```
host          := riscv64-unknown-elf
CC            := $(prefix)/bin/$(host)-gcc
READELF       := $(prefix)/bin/$(host)-readelf
OBJCOPY       := $(prefix)/bin/$(host)-objcopy
```
