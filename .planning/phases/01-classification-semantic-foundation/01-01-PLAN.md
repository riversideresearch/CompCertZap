Add reflection lemmas after the classification definitions, following the `is_protectedb_spec` pattern from backend/RTL.v (line 970):

1. `Lemma builtin_can_replicate_bf_spec (b: builtin_function) : reflect (builtin_can_replicate_bf b = true) (builtin_can_replicate_bf b).`
   - Actually, the standard reflect pattern is: define a Prop form, then prove `reflect Prop Bool`.
   - Since the classification is purely Boolean (no separate inductive needed), use a simpler approach:
   - Define `Definition builtin_can_replicate_bf_prop (b: builtin_function) : Prop := builtin_can_replicate_bf b = true.`
   - Then prove: `Lemma builtin_can_replicate_bf_spec (b: builtin_function) : reflect (builtin_can_replicate_bf_prop b) (builtin_can_replicate_bf b).`
   - Proof: `unfold builtin_can_replicate_bf_prop. destruct (builtin_can_replicate_bf b) eqn:E. left; auto. right; discriminate.`
   - This is the simplest correct reflection. The `is_protectedb_spec` uses a richer inductive Prop, but for now the Boolean-equals-true form is sufficient and much simpler.

2. Alternative simpler approach (preferred): skip the Prop form entirely and just provide:
   - `Lemma builtin_can_replicate_bf_true (b: builtin_function) : builtin_can_replicate_bf b = true -> match b with BI_replicate _ => False | _ => True end.`
   - Proof: `destruct b as [sb|pb|rb]; simpl; [destruct sb | destruct pb | destruct rb]; try discriminate; auto.`
   - This confirms that safe builtins are never protocol builtins.

3. `Lemma builtin_can_replicate_bf_false_replicate (b: replicate_builtin) : builtin_can_replicate_bf (BI_replicate b) = false.`
   - Proof: `reflexivity.`

4. Convenience Boolean decision lemmas:
   - `Lemma builtin_can_replicate_true_bf (ef: external_function) (bf: builtin_function) (name: string) (sg: signature) : ef = EF_builtin name sg -> lookup_builtin_function name sg = Some bf -> builtin_can_replicate_bf bf = true -> builtin_can_replicate ef = true.`
   - Proof: `intros; subst; simpl; rewrite H0; auto.`
   - `Lemma builtin_can_replicate_not_ef_builtin (ef: external_function) : (forall name sg, ef <> EF_builtin name sg) -> builtin_can_replicate ef = false.`
   - Proof: `destruct ef; auto; intros; exfalso; eapply H; eauto.`

Use the rocq-agent MCP server for iterative proof development. Open common/Builtins.v, insert the lemmas, and verify with get_diagnostics.
