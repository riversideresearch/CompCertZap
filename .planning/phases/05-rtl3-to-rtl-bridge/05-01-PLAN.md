<objective>
Prove a generic backward simulation from RTL3 (3-voting) semantics to RTL (2-voting) semantics without requiring the program to have no vote instructions. This replaces the current dependency on Novotes for establishing weak agreement.

Purpose: This bridge is the foundation for removing the novotes pass from the compilation pipeline (Phases 6-7). Currently, weak agreement (RTL3 behaviors refine RTL behaviors) is proved only for programs with no vote instructions. This phase proves it for ALL programs, by showing that vote3 results are always Val.lessdef to vote results.

Output: A complete, compiled RTLagreement.v containing the forward simulation RTL3 -> RTL (which converts to backward simulation since RTL is determinate), plus the behavior-level corollary.
</objective>
