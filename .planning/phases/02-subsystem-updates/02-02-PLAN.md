In the `exec_Ibuiltin` case of the main backward simulation proof (around line 2196), after `inv CODE` introduces the match_instr constructors, there will now be three cases: `match_Ibuiltin_safe`, `match_Ibuiltin_1`, `match_Ibuiltin_2`. Add the proof for `match_Ibuiltin_safe`.

The proof structure mirrors the safe Iop case (lines 1776-1866) but adapted for builtin evaluation:

**Step 1: Show the green copy evaluates correctly.**
Use `eval_builtin_args_rm_2` with `BARGS` to show that `eval_builtin_args ge (fun r => rs' # r) sp m bargs2 vargs` holds (where `vargs` are the same values as the source evaluation), because `match_regsets` ensures `rs' # (fst (rm # r)) = rs # r` for all register args. Then `external_call` produces the same result `vres` and memory `m'` (since the builtin is deterministic -- actually, use `external_call_symbols_preserved` + `senv_preserved` as in the existing proof).

**Step 2: Show the blue copy evaluates correctly.**
After the green copy writes to `res2`, show the blue copy's args (`bargs3`) still evaluate to the same values. The key: blue arg registers are `snd (rm # r)` which are distinct from `res2 = fst (rm # res1)`. Use `eval_builtin_args_rm_3` with appropriate register state reasoning (the green copy's result write to `res2` does not affect blue arg registers due to `rm_wf`/`rm_inv` separation). The blue copy also produces `vres`.

**Step 3: Show the regular (original) copy evaluates correctly.**
After green and blue copies write to `res2` and `res3`, show the original args (`bargs1`) still evaluate to `vargs`. The key: original arg registers `r1` are distinct from `res2 = fst (rm # res1)` and `res3 = snd (rm # res1)` due to `rm_wf`/`rm_inv`. Use `eval_builtin_args_proper` with a `Forall` showing register agreement. The original copy produces `vres` and writes to `res1`.

**Step 4: Establish match_regsets for the successor state.**
After all three copies execute, we have `rs' # res1 = vres`, `rs' # res2 = vres`, `rs' # res3 = vres`. For `match_regsets`, this means all three copies of the result register agree on `vres`. For other registers, use the existing `match_regsets` plus the fact that the `regmap_setres` only modifies `res1`/`res2`/`res3`.

**Step 5: Assemble the compound step.**
The target program takes three `exec_Ibuiltin` steps: green (at pc -> n1), blue (at n1 -> n2), original (at n2 -> succ). Chain with `star_step`. The events from all three `external_call` invocations compose as `E0 ** E0 ** t = t` (if the source event is `t`). Actually, `external_call` for builtins typically produces `E0` for pure builtins, but use the general composition.

Note: For builtins, `external_call` may produce a trace. Three copies will each produce the trace. The compound trace would be `t ** t ** t`. But the source only produces `t`. This is a subtlety -- look at how the safe Iop case handles this (Iop produces no trace, so this is not an issue for Iop). For builtins: all safe builtins classified by `builtin_can_replicate` are `EF_builtin` with `ef_sig` -- check that their `external_call` produces `E0`. The `builtin_function_sem` for these builtins returns `Some v` without I/O, so `external_call` produces `E0`. Use `Events.external_call_trace_length` or show directly that the trace is `E0`.

If the trace composition is problematic, the proof may need a lemma showing `external_call (EF_builtin ...) ... t ... -> builtin_can_replicate (EF_builtin ...) = true -> t = E0`. This should follow from the fact that all safe builtins have `ef_inline = true` and their semantics produce no events.

The overall proof goal is to produce an `exists s2', plus (step ...) s1' t s2' /\ match_states s s2'` where the compound step matches the single source exec_Ibuiltin step.
