1. Define `replication_map_rel` inductive (TMR variant -- two shadows per register):

```coq
(** Relational specification of the TMR replication map construction.
    [replication_map_rel regs rm lo hi] holds when [rm] maps each
    register in [regs] to a pair of distinct shadows in [lo, hi).
    Each original register consumes two positions: r2 at mid, r3 at mid+1.
    The foldM processes the tail first, so the tail occupies [lo, mid)
    and the head register gets shadows at [mid] and [mid+1]. *)
Inductive replication_map_rel
  : list reg -> PMap.t (reg * reg) -> positive -> positive -> Prop :=
| rmr_nil :
  forall rm lo,
    replication_map_rel [] rm lo lo
| rmr_cons :
  forall r regs rm lo mid,
    replication_map_rel regs rm lo mid ->
    rm # r = (mid, Pos.succ mid) ->
    replication_map_rel (r :: regs) rm lo (Pos.succ (Pos.succ mid)).
```

Key design points:
- TMR allocates TWO shadows per register, so `hi = Pos.succ (Pos.succ mid)` (advances by 2)
- `rm # r = (mid, Pos.succ mid)` captures both shadow identities
- Same Option B (minimal inductive, derived range lemma) as DMR plan

2. Prove the derived range lemma:

```coq
Lemma replication_map_rel_range regs rm lo hi :
  replication_map_rel regs rm lo hi ->
  Forall (fun r => let '(r2, r3) := rm # r in
                   lo <= r2 /\ r2 < hi /\ lo <= r3 /\ r3 < hi) regs.
```

Proof sketch: Induction on the `replication_map_rel` derivation.
- Base case (rmr_nil): `Forall _ [] = True`.
- Inductive case (rmr_cons): Head: `rm # r = (mid, Pos.succ mid)`, so `lo <= mid` (from IH structure), `mid < Pos.succ (Pos.succ mid) = hi`, similarly for `Pos.succ mid`. Tail: by IH, all shadows in `[lo, mid)`, then weaken upper bound from `mid` to `hi = Pos.succ (Pos.succ mid)` using `Forall_impl` and `lia`.

Also prove a distinctness helper if needed:

```coq
Lemma replication_map_rel_shadow_distinct regs rm lo hi :
  replication_map_rel regs rm lo hi ->
  Forall (fun r => let '(r2, r3) := rm # r in r2 <> r3) regs.
```

This follows trivially because `r2 = mid` and `r3 = Pos.succ mid`, so `r2 <> r3` by `lia`.

In `backend/RTLtmrspec.v`, replace the monolithic `replication_map_wf_aux` (lines 929-1057) with two new lemmas and rewrite `replication_map_wf`:

1. Prove `foldM_satisfies_rel`:

```coq
Lemma foldM_satisfies_rel regs acc s rm s' pf :
  NoDup regs ->
  foldM
    (fun rm r1 => do r2 <- new_reg; do r3 <- new_reg; ret rm # r1 <- (r2, r3))
    regs acc s = RTLgen.OK rm s' pf ->
  replication_map_rel regs rm s.(st_nextreg) s'.(st_nextreg).
```

Proof approach: Induction on `regs`.
- Base case: `inv Hfold; constructor.`
- Inductive case: Unfold foldM, destruct the bind on the recursive call. The recursive call gives `RTLgen.OK t s'0 pf0`. The head step does TWO `new_reg` calls:
  - First `new_reg` allocates `r2 = st_nextreg s'0`
  - Second `new_reg` allocates `r3 = Pos.succ (st_nextreg s'0)`
  - Then `PMap.set a (r2, r3) t` gives the final map `rm`.
  - Final state nextreg = `Pos.succ (Pos.succ (st_nextreg s'0))`.

Apply IH to the recursive call to get `replication_map_rel regs t (st_nextreg s) (st_nextreg s'0)`.

Then construct `rmr_cons`: need `rm # a = (st_nextreg s'0, Pos.succ (st_nextreg s'0))` which follows from `PMap.gss`.

Important PMap concern: The IH gives facts about the intermediate map `t`, but `rm = PMap.set a (r2, r3) t`. For the tail, the IH states `replication_map_rel regs t lo mid`. But the relation says `rm # r'` for tail registers `r'`, not `t # r'`. Since `rm = PMap.set a _ t` and `a` is not in `regs` (from `NoDup (a :: regs)` -> `~ In a regs`), we have `rm # r' = t # r'` for all `r'` in `regs` by `PMap.gso`.

This means the relation must be "stable under PMap.set of a key not in the list." Prove this as a helper:

```coq
Lemma replication_map_rel_set_other r v regs rm lo hi :
  replication_map_rel regs rm lo hi ->
  ~ In r regs ->
  replication_map_rel regs (rm # r <- v) lo hi.
```

Or equivalently, build the `rmr_cons` for `rm` directly by noting that `rm # a = (r2, r3)` by `PMap.gss`, and the tail relation holds for `rm` because `rm # r' = t # r'` for `r' <> a`.

The simpler approach: prove `replication_map_rel_set_other` first, then apply IH to `t`, lift to `rm` via the helper, and apply `rmr_cons`.

2. Prove `rel_implies_rm_wf`:

```coq
Lemma rel_implies_rm_wf regs rm lo hi :
  replication_map_rel regs rm lo hi ->
  Forall (fun r => r < lo) regs ->
  NoDup regs ->
  rm_wf rm regs.
```

Proof approach: Induction on the `replication_map_rel` derivation.
- Base case (rmr_nil): `rm_wf rm [] = forall r1 r2 r3, In r1 [] -> ...`, vacuously true.
- Inductive case (rmr_cons): Given head `a` with `rm # a = (mid, Pos.succ mid)`, tail satisfies `replication_map_rel regs rm lo mid`, all tail regs `< lo`, tail NoDup. Need to show `rm_wf rm (a :: regs)`.

For TMR `rm_wf`, given `r1` in `a :: regs` with `rm # r1 = (r2, r3)`:
  - **Intra-register NoDup** `[r1; r2; r3]`:
    - If `r1 = a`: `r2 = mid`, `r3 = Pos.succ mid`. `a < lo <= mid`, so `a <> mid` and `a <> Pos.succ mid`. Also `mid <> Pos.succ mid`. All by `lia`.
    - If `r1` in tail: By IH (`rm_wf rm regs`), `NoDup [r1; r2; r3]` holds.

  - **Cross-register NoDup** `[r1; r2; r3; r1'; r2'; r3']`:
    - Both in tail: By IH.
    - `r1 = a`, `r1'` in tail: `r1 = a < lo`, `r2 = mid`, `r3 = Pos.succ mid`. For `r1'`: `r1' < lo`, `rm # r1' = (r2', r3')` with `r2', r3'` in `[lo, mid)` (from `replication_map_rel_range`). So: `{a, r1'}` in `(-inf, lo)`, `{r2', r3'}` in `[lo, mid)`, `{mid, Pos.succ mid}` above. All six are distinct. Build NoDup from range separation.
    - `r1` in tail, `r1' = a`: symmetric to above.

Range separation gives all NoDup clauses without any PMap.gss/gso reasoning.

3. Delete `replication_map_wf_aux` entirely (the old ~128-line monolithic proof).

```coq
Qed.
```

Note: `Regset.elements_3w` provides `NoDupA Regset.E.eq`. Since `Regset.E.eq = Pos.eq = @eq positive`, `NoDupA eq l` is equivalent to `NoDup l`.
