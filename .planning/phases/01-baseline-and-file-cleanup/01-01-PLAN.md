After `make depend` succeeds, build the 4 targeted proof files in parallel:


This is the first build from a clean state, so it will compile all transitive dependencies through the CompCert pipeline. Expect 10-30 minutes. Use `-j$(nproc)` for parallelism.

After the build completes, verify all 4 `.vo` files exist:
```bash
ls -la backend/Novotesproof.vo backend/RTLdmrproof.vo backend/RTLtmrproof.vo backend/RTLtolerant.vo
```

Do NOT run `make proof` (full build of ~190 files) -- only the 4 targeted files are needed per the success criteria.
