**Proof script for each case:**

1. **Inop**: `constructor`. Apply `Regset.for_all_2` to get `For_all`. Use `eqb_sound` to convert `=?` to `=`.

2. **Iop (protected)**: Check `is_protectedb_spec o`. If protected: `destruct_andb` three times to split conjunction. `rewrite forallb_forall` for args. `Regset.for_all_2` on preservation. Apply `wc_Iop_protected`. Args are White via `eqb_sound`. Result is White via `eqb_sound`. Preservation: specialize on `r`, `orb_prop` to case-split disjuncts: `inb` contradicts `~ In` via `not_in_inb`, `Pos.eqb` contradicts `r <> res` via `Pos.eqb_eq`, last disjunct gives color equality via `eqb_sound`.

3. **Iop (safe, not protected)**: `destruct_andb` to split. `is_basicb_spec` for basic color. `forallb_forall` + `eqb_sound` for args. `Regset.for_all_2` on preservation. `Pos.eqb_eq` to discharge `r = res` case, `eqb_sound` for color preservation.

4. **Iload**: Same pattern as Iop protected. `destruct_andb` three times. `forallb_forall` for args White. `eqb_sound` for result White. `Regset.for_all_2` + disjunction discharge for preservation.

5. **Istore**: Same pattern. `eqb_sound` for src White. `forallb_forall` for args White. `Regset.for_all_2` + disjunction discharge for preservation.

6. **Icall**: `destruct_andb` four times. `destruct s0` (fn = inl/inr) for fn color. `forallb_forall` for args White. `eqb_sound` for result White. `Regset.for_all_2` + four-way disjunction discharge (inb, Pos.eqb res, fn match, color equality).
