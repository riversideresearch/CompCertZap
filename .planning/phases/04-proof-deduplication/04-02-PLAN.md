Replace the four near-identical type branches in `maj_voteR_step` (lines 749-832, ~80 lines of proof body) with a parametric approach using an Ltac tactic.

**Current structure:** After `destruct vsem` and `destruct ty; simpl in *; try contradiction; clear H`, there are four branches (Tint, Tfloat, Tlong, Tsingle). Each branch:
1. Inverts `H0` (the `maj_voteR` hypothesis)
2. Constructs the step using `exec_Ibuiltin` with `vote_sem_{int,float,long,single}_ok`
3. Proves register preservation by destructing `rs # r1` and using the appropriate equality decider

The differences between branches:
- **Step construction:** uses `vote_sem_int_ok` vs `vote_sem_float_ok` vs `vote_sem_long_ok` vs `vote_sem_single_ok`
- **Register value case analysis:** `Int.eq_dec`, `Float.eq_dec`, `Int64.eq_dec`, `Float32.eq_dec` + pointer handling differs for Tint/Tlong (need `Archi.ptr64` handling)

**Strategy:** Define a tactic that handles the common structure and uses `first [...]` to dispatch the type-specific parts:

```coq
Ltac solve_maj_voteR_step :=
  match goal with
  | [H0 : maj_voteR _ _ _ _ _ _ _ |- _] => inv H0
  end;
  eexists; split;
  [ econstructor;
    [ eapply exec_Ibuiltin with (vargs := [rs # r1; rs # r2; rs # r3]);
      eauto; repeat constructor;
      rewrite <- Hr3, <- Hr2;
      first [ apply vote_sem_int_ok
            | apply vote_sem_float_ok
            | apply vote_sem_long_ok
            | apply vote_sem_single_ok ];
      apply Val.has_inj_type in Hact; auto
    | apply star_refl
    | reflexivity ]
  | intro r; simpl;
    destruct (peq r r1); subst;
    [ destruct (rs # r1) eqn:Hr1; simpl; try solve [inv Hact];
      try solve [rewrite PMap.gss; reflexivity];
      try solve [destruct (Int.eq_dec i i); simpl; try congruence;
                 rewrite PMap.gss; reflexivity];
      try solve [destruct (Float.eq_dec f f); simpl; try congruence;
                 rewrite PMap.gss; reflexivity];
      try solve [destruct (Int64.eq_dec i i); simpl; try congruence;
                 rewrite PMap.gss; reflexivity];
      try solve [destruct (Float32.eq_dec f f); simpl; try congruence;
                 rewrite PMap.gss; reflexivity];
      try solve [destruct Archi.ptr64 eqn:Harchi; simpl in *; try congruence;
                 destruct (eq_block _ _); simpl; try congruence;
                 destruct (Ptrofs.eq_dec _ _); simpl; try congruence;
                 rewrite PMap.gss; reflexivity];
      try solve [destruct Archi.ptr64 eqn:Harchi; simpl;
                 try solve [simpl in Hact; congruence];
                 destruct (eq_block _ _); simpl; try congruence;
                 destruct (Ptrofs.eq_dec _ _); simpl; try congruence;
                 rewrite PMap.gss; reflexivity]
    | rewrite PMap.gso; auto ] ].
```

