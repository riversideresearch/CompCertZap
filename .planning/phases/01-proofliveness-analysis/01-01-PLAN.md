**File structure (in order):**

1. **Header comment:** Identify this as the conservative liveness analysis for the fault tolerance proof.

2. **Imports:** Exactly these, in this order:
   ```

   Require Import Maps.
   ```

3. **Helper definitions:** Clone identically from Liveness.v (lines 30-51):
   - `Notation reg_live := Regset.add.`
   - `Notation reg_dead := Regset.remove.`
   - `reg_option_live`, `reg_sum_live`, `reg_list_live`, `reg_list_dead`

4. **Transfer function (PLIV-01):** The key difference from Liveness.v. Define `transfer (f: function) (pc: node) (after: Regset.t) : Regset.t` with:
   - `None` case: return `Regset.empty` (identical to Liveness.v -- CRITICAL for analyze_solution side condition)
   - `Iop op args res s` case: ALWAYS `reg_list_live args (reg_dead res after)` -- NO `if Regset.mem res after` guard
   - `Iload chunk addr args dst s` case: ALWAYS `reg_list_live args (reg_dead dst after)` -- NO `if Regset.mem dst after` guard
   - All other instruction cases: IDENTICAL to Liveness.v (Inop, Istore, Icall, Itailcall, Ibuiltin, Icond, Ijumptable, Ireturn)

5. **Solver instantiation (PLIV-02):**
   ```coq
   Module RegsetLat := LFSet(Regset).
   Module DS := Backward_Dataflow_Solver(RegsetLat)(NodeSetBackward).
   Definition analyze (f: function): option (PMap.t Regset.t) :=
     DS.fixpoint f.(fn_code) successors_instr (transfer f).
   ```
   Note: Using same module names as Liveness.v is fine since no file imports both.

6. **Fixpoint theorem (PLIV-03):**
   ```coq
   Lemma analyze_solution:
     forall f live n i s,
     analyze f = Some live ->
     f.(fn_code)!n = Some i ->
     In s (successors_instr i) ->
     Regset.Subset (transfer f s live!!s) live!!n.
   Proof.
     unfold analyze; intros. eapply DS.fixpoint_solution; eauto.
     intros. unfold transfer; rewrite H2. apply DS.L.eq_refl.
   Qed.
   ```
   This proof is IDENTICAL to Liveness.v because the side condition only concerns the `fn_code!n = None` case, which is the same in both transfer functions.

7. **Monotonicity helper (prerequisite for PLIV-04):**
   ```coq
   Lemma reg_list_live_incl:
     forall args s r,
     Regset.In r s -> Regset.In r (reg_list_live args s).
   Proof.
     induction args; simpl; intros.
     - assumption.
     - apply IHargs. apply Regset.add_2. assumption.
   Qed.
   ```
   This is REQUIRED before `reg_list_live_in`. Without it, the induction in `reg_list_live_in` gets stuck at the `r = a` subcase (see Research pitfall 3).

8. **Membership lemma (PLIV-04):**
   ```coq
   Lemma reg_list_live_in:
     forall r args s,
     In r args -> Regset.In r (reg_list_live args s).
   Proof.
     induction args; simpl; intros.
     - contradiction.
     - destruct H as [H | H].
       + subst. apply reg_list_live_incl. apply Regset.add_1. reflexivity.
       + apply IHargs. assumption.
   Qed.
   ```
   If `Regset.add_1` with `reflexivity` fails (due to OrderedPositive.eq), try `apply Regset.add_1. apply OrderedPositive.eq_refl.` or `apply Regset.add_1. unfold OrderedPositive.eq. reflexivity.` instead.

9. **Do NOT include** the `last_uses_at` and `last_uses` definitions from Liveness.v -- they are specific to dead code elimination and not needed here.
