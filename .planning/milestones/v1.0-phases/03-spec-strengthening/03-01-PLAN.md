1. Define `replication_map_rel` inductive (DMR variant -- single shadow per register):

```coq
(** Relational specification of the DMR replication map construction.
    [replication_map_rel regs rm lo hi] holds when [rm] maps each
    register in [regs] to a distinct shadow in the range [lo, hi).
    The foldM processes the tail first, so the tail occupies [lo, mid)
    and the head register gets shadow at [mid]. *)
Inductive replication_map_rel
  : list reg -> PMap.t reg -> positive -> positive -> Prop :=
| rmr_nil :
  forall rm lo,
    replication_map_rel [] rm lo lo
| rmr_cons :
  forall r regs rm lo mid,
    replication_map_rel regs rm lo mid ->
    rm # r = mid ->
    replication_map_rel (r :: regs) rm lo (Pos.succ mid).
```

Key design points:
- Minimal inductive (Option B from research): no bundled Forall in constructor
- `rmr_cons` reflects foldM tail-first order: tail built `[lo, mid)`, head at `mid`
- `rm # r = mid` captures exact shadow identity (not just range)

2. Prove the derived range lemma:

```coq
Lemma replication_map_rel_range regs rm lo hi :
  replication_map_rel regs rm lo hi ->
  Forall (fun r => lo <= rm # r < hi) regs.
```

Proof sketch: Induction on the `replication_map_rel` derivation.
- Base case (rmr_nil): `Forall _ [] = True`.
- Inductive case (rmr_cons): Head: `rm # r = mid` so `lo <= mid < Pos.succ mid = hi`. Tail: by IH, all shadows in `[lo, mid)`, then weaken upper bound from `mid` to `hi = Pos.succ mid` using `Forall_impl` and `lia`.

Do NOT modify anything below the insertion point yet -- that comes in Task 2.

In `backend/RTLdmrspec.v`, replace the monolithic `replication_map_wf_aux` (lines 813-915) with two new lemmas and rewrite `replication_map_wf`:

1. Prove `foldM_satisfies_rel`:

```coq
Lemma foldM_satisfies_rel regs acc s rm s' pf :
  foldM
    (fun rm r1 => do r2 <- new_reg; ret rm # r1 <- r2)
    regs acc s = RTLgen.OK rm s' pf ->
  replication_map_rel regs rm s.(st_nextreg) s'.(st_nextreg).
```

Proof approach: Induction on `regs`.
- Base case: `inv Hfold; constructor.`
- Inductive case: Unfold foldM, destruct the bind on the recursive call. The recursive call gives `RTLgen.OK t s'0 pf0`. Apply IH to get `replication_map_rel regs t (st_nextreg s) (st_nextreg s'0)`. The head step does `new_reg` (allocating `st_nextreg s'0`) then `PMap.set`. So `rm # a = st_nextreg s'0` (via `PMap.gss`). State after head: `st_nextreg = Pos.succ (st_nextreg s'0)`. Apply `rmr_cons`.

Important: The `Forall` precondition from the old lemma is NOT needed for this lemma -- the relation captures structure, not well-formedness. But you need to track that `new_reg` advances `st_nextreg` by exactly 1.

Note on PMap.gss: After `ret rm # r1 <- r2`, the map is `PMap.set r1 r2 rm'` where `rm'` came from the recursive call. The IH is about `rm'`, not the final `rm`. The `rmr_cons` constructor says `rm # r = mid` where `rm` is the FINAL map. Since `PMap.set r1 r2 rm'` gives `(PMap.set r1 r2 rm') # r1 = r2` by `PMap.gss`, the head is fine. For the tail registers, the IH gives facts about `rm'`, but we now have `PMap.set r1 r2 rm'`. We need that for `r' <> r1`, `(PMap.set r1 r2 rm') # r' = rm' # r'` by `PMap.gso`. This means we need to know `r1` is NOT in the tail list, i.e., `NoDup (r1 :: regs)` or at minimum `~ In r1 regs`.

Approach: Either (a) add a precondition `NoDup regs` (which is satisfied because the input comes from `Regset.elements`, which is NoDup), or (b) restructure the inductive to handle PMap overwrite semantics. Option (a) is recommended -- add `NoDup regs` as a precondition.

Actually, re-examine the existing proof: the old `replication_map_wf_aux` does NOT require NoDup on the input -- it works with the final PMap directly. The `replication_map_rel` also describes the final PMap. Since PMap is last-write-wins, if a register appears twice, only the last write matters. However, the relational spec says `rm # r = mid` for the HEAD r, but the tail IH says `rm' # r' = something` for tail registers, and after PMap.set, `rm # r' = rm' # r'` only if `r' <> r`. For NoDup lists, this is guaranteed.

Since `Regset.elements` guarantees NoDup and `replication_map_wf` calls with `fun_regs_list f` which is `Regset.elements (all_regs ...)`, adding `NoDup regs` is safe. Add it as a precondition.

2. Prove `rel_implies_rm_wf`:

```coq
Lemma rel_implies_rm_wf regs rm lo hi :
  replication_map_rel regs rm lo hi ->
  Forall (fun r => r < lo) regs ->
  NoDup regs ->
  rm_wf rm regs.
```

Proof approach: Induction on the `replication_map_rel` derivation.
- Base case (rmr_nil): `rm_wf rm [] = forall r, In r [] -> ...`, vacuously true.
- Inductive case (rmr_cons): Given head `a` with `rm # a = mid`, tail satisfies `replication_map_rel regs rm lo mid`, all tail regs `< lo`, tail NoDup. Need to show `rm_wf rm (a :: regs)`.

For any `r` in `a :: regs`:
  - If `r = a`: `r <> rm # r` because `r < lo <= mid = rm # r` by `Forall` hypothesis and range. For distinctness with any `r'` in tail: `r' < lo` and `rm # r' < mid` (from `replication_map_rel_range`) and `rm # a = mid`, so all four `[r; mid; r'; rm # r']` are in disjoint ranges.
  - If `r` in tail: Use IH for `rm_wf rm regs`, handle the new cross-pair with `a` using the same range argument.

The key insight: original registers are all `< lo`, shadow registers are all in `[lo, hi)`, so originals and shadows are disjoint. Different shadows are at different positions within `[lo, hi)` because the relation assigns distinct positions.

No PMap.gss/gso reasoning should appear in this proof -- all facts come from `replication_map_rel` and `replication_map_rel_range`.

3. Delete `replication_map_wf_aux` entirely (the old ~102-line monolithic proof).

```coq
Lemma replication_map_wf f rm s pf :
  replication_map f (init_state f) = RTLgen.OK rm s pf ->
  rm_wf rm (fun_regs_list f).
Proof.
  intro H.
  eapply rel_implies_rm_wf.
  - eapply foldM_satisfies_rel; eauto.
    (* NoDup from Regset.elements *)
    apply Regset.elements_3w.
  - apply Forall_forall; intros r Hin.
    apply in_lt_max_reg; auto.
  - apply Regset.elements_3w.
Qed.
```

Note: `replication_map` unfolds to the relevant `foldM` call. The `NoDup` precondition is discharged by `Regset.elements_3w` (which provides `NoDupA` -- may need `NoDupA_NoDup` coercion or use `SetoidList` lemmas). Verify the exact Coq lemma name for NoDup on Regset.elements.
