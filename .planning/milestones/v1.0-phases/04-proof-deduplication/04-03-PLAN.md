Lemma check_col_Iop_protected_sound pc op args res succ :

For the Ibuiltin case, the original proof chains `destruct (is_green_smove_builtinb_spec e)`, `destruct (is_blue_smove_builtinb_spec e)`, `destruct (is_vote_builtinb_spec e)`. Extract four separate lemmas with appropriate preconditions. The "other" case needs negative preconditions:
```coq
Lemma check_col_Ibuiltin_other_sound pc ef args res succ :
  ~ is_green_smove_builtin ef ->
  ~ is_blue_smove_builtin ef ->

  check_col_instr pc (Ibuiltin ef args res succ) = true ->
  wc_instruction (fun n r => (col n) ! r) pc (Ibuiltin ef args res succ).
```

Place all per-instruction lemmas BEFORE the main `check_col_instr_sound` lemma, in the same section.

Then rewrite the main lemma as a dispatcher:
```coq
Lemma check_col_instr_sound (pc : node) (instr : instruction) :
  check_col_instr pc instr = true ->
  wc_instruction (fun n r => (col n) ! r) pc instr.
Proof.
  destruct instr; simpl; intro Hcheck; try congruence.
  - apply check_col_Inop_sound; auto.
  - destruct (is_protectedb_spec o).
    + apply check_col_Iop_protected_sound; auto.
    + apply check_col_Iop_safe_sound; auto.
  - apply check_col_Iload_sound; auto.
  - apply check_col_Istore_sound; auto.
  - apply check_col_Icall_sound; auto.
  - apply check_col_Itailcall_sound; auto.
  - destruct (is_green_smove_builtinb_spec e).
    + apply check_col_Ibuiltin_smove_green_sound; auto.
    + destruct (is_blue_smove_builtinb_spec e).
      * apply check_col_Ibuiltin_smove_blue_sound; auto.
      * destruct (is_vote_builtinb_spec e).
        { apply check_col_Ibuiltin_vote_sound; auto. }
        { apply check_col_Ibuiltin_other_sound; auto. }
  - apply check_col_Icond_sound; auto.
  - apply check_col_Ijumptable_sound; auto.
  - apply check_col_Ireturn_sound; auto.
Qed.
```

IMPORTANT NOTES:
- All lemmas must be inside the same Section (CHECK_PROGRAM or wherever check_col_instr_sound currently lives) so they have access to `col`, `prog`, etc.
- The `simpl` at the top of the main lemma may need to be removed or adjusted -- the per-instruction lemmas may need their own `simpl` or `unfold check_col_instr` to reduce correctly. Test both approaches.
- For the Ibuiltin sub-case lemmas, the `check_col_instr` function's definition determines what `simpl` produces. The per-instruction lemma may need to take the reduced form directly. Examine what `simpl` produces for `check_col_instr pc (Ibuiltin ef args res succ)` and use that as the hypothesis form.
