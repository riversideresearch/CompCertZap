## Compilation Pipeline

**Proof Stage:**
```
.v files (Coq proofs) -> coqc -> .vo files (verified objects)
```
Located in: `lib/`, `common/`, `backend/`, `x86/`, `cfrontend/`, `driver/`

**Extraction Stage:**
```
.vo files -> coqc extraction/extraction.v -> OCaml .ml files
```
Extracted OCaml goes to `extraction/` directory, then to source directories

**OCaml Compilation Stage:**
```
.ml files (extracted + hand-written) -> ocamlopt -> .cmx (native) / .cmo (bytecode)
Combined into: ccomp (compiler binary), clightgen (C AST generator), vcomp (Cminor importer)
```

**Runtime Library:**
```
.S files (x86-64 assembly) -> gcc -c -> .o object files
Object files + hand-written C -> ar -> libcompcert.a
```

## Feature Flags

**Compiler Options (runtime):**
- `-tmr` - Enable Triple Modular Redundancy fault tolerance (via RTLtmr pass)
- `-dmr` - Enable Dual Modular Redundancy
- `-c` - Compile to object file only (no link)
- `-S` - Generate assembly file only
- `-E` - Preprocess only
- `-interp` - Interpret C code directly (machine interpreter)
- `-drtl` - Dump RTL intermediate representation
- `-dclight` - Dump Clight intermediate representation
- `-dasm` - Preserve generated assembly file
- `-O2`, `-Os` - Optimization levels

**Color System (Fault Tolerance):**
- RTL programs must be well-colored (Red/Green/Blue/White/Pink assignments)
- Color checking via `RTLcolorcheck.check_program` before final compilation
- Inferred by `RTLinfercolor.infer_coloring` (unverified OCaml oracle)
