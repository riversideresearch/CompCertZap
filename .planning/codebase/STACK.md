# Technology Stack

**Analysis Date:** 2026-03-03

## Languages

**Primary:**
- **Coq** 8.15-9.0 - Formal proof assistant; used for semantic preservation proofs and verified compiler transformations
- **OCaml** 4.05-4.14 - Functional programming language; extraction target from Coq proofs; runtime compiler implementation
- **Menhir** (parser generator) - Generates OCaml parser from `.mly` grammar files; produces `Parser.ml` from `Parser.vy`

**Secondary:**
- **C** (subset) - Source language being compiled
- **x86-64 Assembly** - Primary target architecture (configured via `x86_64-linux`)
- **ARM, PowerPC, RISC-V** - Supported alternative target architectures (via configuration)

## Runtime

**Environment:**
- **OCaml 4.14.2** - Primary execution runtime; compiler binaries compiled to native code (`ccomp`, `clightgen`, `vcomp`)
- **Operating System:** Linux x86_64 (primary target); supports Windows (Cygwin), macOS via cross-platform configuration
- **GCC toolchain** - Used for assembly (`gcc -m64 -c`), linking (`gcc -m64`), preprocessing via `/usr/bin/gcc -m64 -U__GNUC__ -E`

**Package Manager:**
- **OPAM** (OCaml Package Manager) - Manages OCaml dependencies; current switch: `4.14.2`
- Lockfile: Not explicitly versioned; dependencies bundled locally

## Frameworks

**Core:**
- **Coq Standard Library** 8.15-9.0 - Proof foundations (tactics, tactics, type theory, stdlib modules)
- **CompCert Coq Library** (in-codebase) - Custom Coq modules for compiler semantics:
  - `lib/` - General utilities (Maps, Integers, Coqlib, UnionFind)
  - `common/` - Shared definitions (AST, Values, Memory, Smallstep)
  - `cfrontend/` - C semantics and frontend languages
  - `backend/` - RTL semantics, optimizations, register allocation

**Testing:**
- **Coq Proof Verification** - Proofs checked via `coqc` (no separate test runner)
- No OCaml unit test framework detected; manual testing via compilation of C files
- Configuration checking via `make check-admitted` (verifies no `Admitted` proofs remain)

**Build/Dev:**
- **Make** (GNU Make 3.80+) - Primary build system
  - `Makefile` - Coq proof compilation and top-level orchestration
  - `Makefile.extr` - OCaml extraction and compilation phase
  - `Makefile.menhir` - Parser generation configuration
- **Coq extraction** - Automated translation from Coq to OCaml via `coqc` with extraction plugins
- **Menhir** - Parses C code into AST using table-based parser generator (`--table` mode)

## Key Dependencies

**Critical:**
- **Flocq** (local bundled copy) - Floating-point arithmetic library for Coq; used by IEEE 754 semantics
- **MenhirLib** (local bundled copy) - Support library for Menhir-generated parsers; included in `backend/` via `-I +menhir`
- **OCaml stdlib** - Core libraries: `unix` (file operations, system calls), `str` (string regex), standard modules
- **OCaml standard includes** - Installed via OPAM; menhirLib package provides runtime for parser

**Infrastructure:**
- **Coq compiler** (`coqc`) - Verifies and compiles `.v` proof files to `.vo` (Coq compiled objects)
- **OCaml compiler** (`ocamlc`, `ocamlopt`, `ocamlopt.opt`) - Compiles extracted OCaml to native binaries
- **Menhir** - Generates parser from `Parser.vy` to `Parser.v` (Coq) and `Parser.ml` (OCaml)

## Configuration

**Environment:**
- **Compilation target:** Configured via `./configure <target>` script (e.g., `x86_64-linux`, `arm-eabi`)
- **Makefile.config** - Generated by `configure`; contains:
  - Architecture selection (ARCH, BITSIZE, ENDIANNESS, MODEL)
  - Tool paths (COQBIN, ocamlc/ocamlopt, menhir)
  - Compiler flags for C preprocessing, assembly, linking
  - Library paths (MENHIR_DIR from OPAM)
  - Feature flags (HAS_RUNTIME_LIB, HAS_STANDARD_HEADERS, CLIGHTGEN)

**Build:**
- `Makefile` - Main build orchestration; defines pipeline: `proof` → `extraction` → `ccomp` → `runtime`
- `_CoqProject` - Coq project file; defines include paths (`-R` flags for all directories)
- `VERSION` - Semantic version file (currently 3.16)
- `compcert.ini` - Generated runtime configuration; contains preprocessor, assembler, linker paths and options
- `.merlin` - Editor support for OCaml (Merlin)

## Platform Requirements

**Development:**
- **Coq** 8.15-9.0 (installed via OPAM or system)
- **OCaml** 4.05-4.14 (installed via OPAM; current: 4.14.2)
- **GNU Make** 3.80 or later
- **Menhir** 20211128 or later (parser generator)
- **GCC toolchain** - For native code compilation (C preprocessing, assembly, linking)
- **Optional:** clightgen tools (C-to-Clight translator) enabled via `-clightgen` flag during configure

**Production:**
- **Linux x86_64** (primary), x86_32, ARM, PowerPC, RISC-V, AArch64, macOS (via cross-compilation)
- **Compiled binaries:** `ccomp` (main compiler), `clightgen` (C-to-Clight), `vcomp` (verification tool)
- **Runtime library** - C runtime support (`runtime/` directory, compiled to `libcompcert.a`)
- **No external services** - Self-contained compiler; produces standalone executables

## Compiled Outputs

**Intermediates:**
- `.vo` files - Coq compiled proofs (generated from `.v` sources)
- `.ml` files - OCaml extracted from Coq (generated in `extraction/` by `COQEXEC`)
- `.mly`/`.mll` - Parser/lexer sources (Menhir and ocamllex)
- `.cmx`/`.cmo` files - OCaml compiled modules (native/bytecode)

**Finals:**
- **`ccomp`** - Main C compiler binary (native code)
- **`clightgen`** - C-to-Clight tool (optional)
- **`vcomp`** - Verification/import tool
- **`libcompcert.a`** - Runtime support library (C code compiled via GCC)
