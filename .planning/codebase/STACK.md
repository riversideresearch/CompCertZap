# Technology Stack

**Analysis Date:** 2026-03-14

## Languages

**Primary:**
- **Coq** 8.15–9.1 - Formal verification language for entire compiler correctness proofs
  - Core usage: `backend/`, `cfrontend/`, `common/`, `lib/`, `driver/Compiler.v`, `driver/Complements.v`
  - Fault tolerance extension: `backend/RTLfault.v`, `backend/RTLcolor.v`, `backend/RTLcolorcheck.v`, `backend/RTLtolerant.v`, `backend/RTLdmr.v`, `backend/RTLtmr.v`

- **OCaml** 4.14.2 - Imperative implementation language for compiler passes and extraction
  - Extracted from Coq: `extraction/extraction.v` directs Coq-to-OCaml extraction
  - Manual OCaml code: `cparser/` (C parser), `driver/` (CLI and orchestration), `backend/` (unverified oracles)
  - Key files: `driver/Driver.ml` (main entry point), `backend/RTLinfercolor.ml` (color inference oracle)

- **C** - Runtime support library and standard headers
  - Location: `runtime/` (architecture-specific implementations in `runtime/{x86_64,arm,aarch64,powerpc,riscV}/`)
  - Example: `runtime/c/i64.h` and `*.S` assembly stubs for 64-bit integer operations

- **Assembly (x86-64, ARM, PowerPC, RISC-V)** - Architecture-specific code generation
  - Generated by Coq passes: `Asmgen.v`, architecture-specific `Asm.v` (e.g., `x86/Asm.v`)
  - Manual: architecture-specific runtime stubs in `runtime/` subdirectories

## Runtime

**Environment:**
- **OCaml Runtime (4.14.2)** - Executes extracted OCaml bytecode/native code
- **GCC Toolchain** - Assembles and links generated assembly
  - Config: `Makefile.config` defines `CC=gcc -m64`, `CASM=gcc`, `CLINKER=gcc` (x86_64-linux target)
  - Multi-architecture support: PowerPC, ARM, AArch64, RISC-V, x86-32/64

**Package Manager:**
- **OPAM** 4.14.2 switch - OCaml package manager
  - Dependencies via OPAM: `menhirLib` (parser library), located at `/home/alex/.opam/4.14.2/lib/menhirLib`
  - Lockfile: No package.json/opam.lock equivalent in repo root; dependencies specified via configure flags

## Frameworks

**Core:**
- **Coq Proof Assistant** 8.15–9.1 - Framework for formal verification
  - Configuration: `_CoqProject` defines `-R` include paths for modules
  - Coq options in `Makefile`: `-w` flags silence specific warnings (unused-pattern-matching-variable, deprecated-instance-without-locality, etc.)

- **Menhir Parser Generator** - LR(1) parser for C syntax
  - Configuration: `Makefile.menhir`, `cparser/Parser.vy` (Menhir grammar)
  - Mode: Table-driven (`MENHIR_TABLE=true`), flags: `--table --no-stdlib -la 1`
  - Lexer: `cparser/Lexer.mll` (ocamllex-based)
  - Output: Generates `cparser/Parser.ml(i)` from `.vy` file

**Build/Dev:**
- **Make** - Primary build orchestration
  - Stages: `make proof` (Coq compilation), `make extraction` (Coq→OCaml), `make ccomp` (OCaml compilation), `make runtime`
  - Coq dependency tracking: `coqdep` generates `.depend` file
  - OCaml dependency tracking: `ocamldep` via `Makefile.extr`

- **OCaml Native Code Compiler** (`ocamlopt`) - Generates native binaries
  - Conditionally enabled via `OCAML_NATIVE_COMP=true` and `OCAML_OPT_COMP=true`
  - Uses `.opt` variants of tools (e.g., `ocamlc.opt`, `ocamlopt.opt`)

- **OCaml Bytecode Compiler** (`ocamlc`) - Fallback if native unavailable

## Key Dependencies

**Critical (Bundled):**
- **Flocq** (Floating-point formalization in Coq)
  - Source: `flocq/` (local copy included)
  - Config: `LIBRARY_FLOCQ=local` (default; can use external via `-use-external-Flocq`)
  - Modules: `Core/`, `Prop/`, `Calc/`, `IEEE754/` (binary floating-point)

- **MenhirLib** (OCaml library for Menhir)
  - Source: `MenhirLib/` (local Coq formalization of parser tables)
  - Config: `LIBRARY_MENHIRLIB=local` (can use external via `-use-external-MenhirLib`)
  - Runtime: `menhirLib.cmxa` linked into final binary

**Infrastructure (Extracted):**
- **Coq Standard Library** - Used throughout proofs
  - Key imports: `From Coq Require`, `From Stdlib Require` (Rocq naming)
  - Extraction target: `ExtrOcamlBasic`, `ExtrOcamlNativeString` for OCaml compatibility

- **CompCert Lib Utilities**
  - `lib/Coqlib.v` - Coq tactics and automation
  - `lib/Maps.v` - Functional finite maps
  - `lib/Integers.v` - Bit-vector integers
  - `lib/Floats.v` - IEEE754 floating-point (uses Flocq)
  - `lib/UnionFind.v` - Disjoint-set forest data structure
  - Extracted to OCaml modules

**OCaml Standard Library Modules (via Stdlib):**
- `Printf` - String formatting (`sprintf`, `printf`, `eprintf`)
- `Str` - Regular expressions (used in `Commandline.ml` pattern matching)
- `Unix` - System calls (linked via `-I +unix` in `Makefile.extr`)
- `Camlcoq` - Manual OCaml adapter for Coq-extracted types (custom, in `lib/Camlcoq.ml`)

## Configuration

**Environment:**
- **Makefile.config** (generated by `./configure`)
  - Defines architecture: `ARCH=x86`, `BITSIZE=64`, `SYSTEM=linux`
  - Toolchain: `CC`, `CASM`, `CLINKER`, `CPREPRO` (with `-m64` flags for x86_64)
  - Paths: `PREFIX=/usr/local`, `BINDIR`, `LIBDIR`, `COQDEVDIR`
  - Feature flags: `HAS_RUNTIME_LIB=true`, `HAS_STANDARD_HEADERS=true`, `INSTALL_COQDEV=false`, `CLIGHTGEN=false`

- **.CoqProject** - Coq project configuration
  - Coq include paths: `-R lib compcert.lib`, `-R backend compcert.backend`, etc.
  - Standard library prefixes: `-R flocq Flocq`, `-R MenhirLib MenhirLib`

- **VERSION** (static metadata)
  - Current: `version=3.17`, base CompCert 3.17 release

**Build Flags:**
- **Coq Compilation** (`COQCOPTS`)
  - Warning suppressions: `-w -unused-pattern-matching-variable`, `-w -deprecated-since-8.19/8.20`
  - Extraction: `COQEXTRACTOPTS` with additional flags: `-w -change-dir-deprecated`, `-w -extraction-default-directory`
  - Extraction command: `$(COQBIN)coqtop` with `-batch -load-vernac-source`

- **OCaml Compilation** (`COMPFLAGS` in `Makefile.extr`)
  - Strict mode: `-strict-sequence -safe-string -g`
  - Warning-as-error: `+warn-error +a` (if `.git` exists, else relaxed)
  - Include paths: `-I extraction -I lib -I common -I x86 -I backend -I cfrontend -I cparser -I driver -I export -I debug -I import`
  - Menhir libs: `-I "$(MENHIR_DIR)" -I +str -I +unix`

## Platform Requirements

**Development:**
- Coq 8.15–9.1 installed (checked at configure time via `coqc --print-version`)
- OCaml 4.14.2 (OPAM switch)
- GCC with 64-bit support (`gcc -m64`)
- GNU Make (POSIX make may fail on some targets)
- Menhir parser generator (`menhir` executable)

**Production (Compiled Binaries):**
- **Deployment target:** x86_64-linux (configured via `./configure x86_64-linux`)
- Alternative targets via configure: ppc-{eabi,linux}, arm-{eabi,linux}, x86_32-{linux,bsd}, x86_64-{bsd,macos,cygwin}, rv32/64-linux, aarch64-{linux,macos}
- Runtime: GCC-compatible assembler and linker (part of GCC toolchain)
- Standard C headers: optional (`-no-standard-headers` flag disables install of `runtime/include/`)

**Compiler Output:**
- Generates POSIX x86-64 assembly (`.s` files)
- Optional JSON dump of AST via `AsmToJSON` module (`-sdump` flag, default suffix `.json`)
- Final executable linkage with `libcompcert.a` (runtime library with 64-bit stubs)
